# Мой диабет

Веб-приложение для конструктора питания и поддержки самоконтроля диабета.

## Состав проекта

- `index.html` — интерфейс веб-приложения.
- `assets/` — изображения продуктов и блюд.
- `core/`, `adapters/`, `integrations/`, `i18n/` — модули приложения.
- `server/` — серверная часть синхронизации на Node.js.

## Сервер

Для серверной части требуется Node.js 18 или новее. Команды и зависимости определены в `server/package.json`.

```bash
cd server
npm install
npm start
```

Перед запуском настройте необходимые параметры окружения и подключение к PostgreSQL согласно конфигурации сервера. Не добавляйте секреты, реальные медицинские данные или пользовательские базы в репозиторий.
