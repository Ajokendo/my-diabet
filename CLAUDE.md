# «Мой диабет» — заметки для продолжения работы

Помощник для семьи ребёнка с диабетом 1 типа: дневник, еда и ХЕ, расчёт инсулина по коэффициентам врача, сахар с сенсора, анализы, отчёт врачу, SOS и памятка для школы. Автор — отец ребёнка («Ата»), даёт обратную связь скриншотами с телефона (Android, Chrome). Общаемся по-русски.

## Где что работает
- Сайт: https://my-diabet.pages.dev — Cloudflare Pages, деплой автоматически из `main` этого репозитория.
- Сервер автора: Cloudflare Worker `my-diabet.ajokendo.workers.dev` + D1. Код — `server/cloudflare-worker.js`. Автор вставляет его сам: Cloudflare → Worker → Edit code → Deploy. Файл для него кладём через мост на его ПК: `C:\Users\aoroz\Downloads\Pics MD\cloudflare-worker-NEW-v64.js`.
- Версия сервера — `SERVER_VERSION` в начале файла воркера. Приложение сравнивает `/health` с ним и предлагает семьям скачать новый код.

## Модель распространения (решено)
- Бесплатно, «Light»: всё работает на телефоне без регистрации и без сервера.
- Кому нужно больше (общий дневник на нескольких телефонах, сахар с сенсора, уведомления, фото еды, распознавание выписок) — ставят **свой** бесплатный сервер Cloudflare по инструкции. Поддержки нет.
- Сервер автора закрыт для новых дневников (OWNER_EMAILS ∪ ALLOWED_EMAILS; OPEN_REGISTRATION=1 открывает). Импорт истории чужим семьям — максимум 3 дня. FREE_PHOTOS=3 бесплатных фото через сервер автора.
- Автор не продаёт, не оформляет ИП, не хочет, чтобы ему писали. В документах для других — без ссылок на автора и без «напишите мне».
- Ссылку раздают эндокринологам и Ассоциации диабетиков.

## Выпуск версии (каждая правка)
1. `sed -i 's/v64\.N/v64.N+1/g' index.html js/app.js` (версия в `?v=` скриптов и в app.js).
2. Запись сверху в `CHANGELOG.md` (`## v64.N — ДД.ММ.ГГГГ`).
3. Коммит с подписью Co-Authored-By/Claude-Session, `git push origin HEAD:refs/heads/main`.
4. Если менялись иконки — поднять `CACHE` в `sw.js` и `?v=` у иконок.
Текущая версия на 14.11.2026 — **v64.71**.

## Устройство
- `index.html` — вся разметка; `js/app.js` — основная логика (show(), рендеры, калькулятор); `css/app.css` — стили (новые правила дописываются в конец с комментарием версии).
- `js/sync.js` — общий дневник/свой сервер; `js/cgm.js` — сенсор (DMCgm.latest(), fillCalc); `js/care.js` — «Безопасность» (SOS, памятка, места уколов, резервная копия); `js/voice.js` — голосовой ввод еды (ru-RU); `js/guide.js` — инструкция (группы тем; серверные — в конце, раздел «Расширенные возможности»); `js/datefmt.js` — подпись ДД.ММ.ГГГГ поверх полей даты.
- `data/catalog.js` — база продуктов (у каждого `h` = md5[:8] картинки — обновлять при смене фото); переименования — `CATALOG_RENAMES` в app.js; меры — `js/measures.js`.
- Без своего сервера в нижнем меню «🩸 Сахар» вместо «Фото» (`hasOwnServer()` в app.js).

## Кыргызский язык
- `js/i18n.js` — переводит готовый интерфейс (TreeWalker + MutationObserver), правила для строк с числами (RULES/TOK), переключатель «РУС | КЫР» на главной.
- `js/i18n-ky.js` — словарь, **генерируется**: источники в `tools/i18n/d*.py`, `h*.py` → `python3 tools/i18n/genky.py` (поправить пути внутри на свои). Новые русские строки в интерфейсе — добавлять перевод туда же.
- Автор проверил перевод: «не стыдно показать носителю». Фразу «Перевод машинный — уточнения будут добавляться» оставить.
- Термины: сахар — кант, приём пищи — тамактануу, ед. — бир., БЖЕ — БМБ, Ж — М.

## Инструменты (tools/)
- `tools/guide/` — скриншоты инструкции (Playwright на демо-данных): `run.py`, `run_new.py` → shots → webp 585/300 px в `assets/guide/` → `pdf.py` собирает `assets/guide/my-diabet-guide.pdf`. После изменений главного экрана — переснять.
- `tools/audit.py`, `tools/audit_ky.py` — прогон всех разделов на ширине телефона (ru/ky), ищет ошибки и вылезание.
- `tools/deck/cap.py` — скриншоты для презентации. Презентация (Slides) и документы «Функции и настройка», «Как расти без перегрузки» — артефакты в аккаунте автора.
- Локальный сервер для проверок: `python3 -m http.server 8765` в корне.

## Правила (всегда)
- Не придумывать дозы инсулина, ICR/ISF; калькулятор считает только по коэффициентам врача. IOB — только по согласованию с врачом.
- Не просить и не принимать ключи и секреты (Anthropic API key, CRED_KEY, PHOTO_ACCESS_CODE, токены Cloudflare, секрет Nightscout). Не входить в аккаунты автора.
- Медицинские документы семьи — личные данные; в инструкции и презентации — только демо-данные.
- Не помогать с модифицированными приложениями (LinX).
- Удаление файлов на ПК автора — только с его разрешения.
- КБЖУ продуктов — по нашим «лекалам»; сахар в чай не добавлять (сахар — отдельный продукт).
