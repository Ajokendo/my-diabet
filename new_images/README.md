# new_images

Изолированная папка для подготовки новых изображений продуктов.

Приложение эту папку **не использует**: рабочие изображения лежат в `assets/`. Картинки здесь не влияют на рабочую версию до отдельной интеграции.

Стандарт: JPEG 512×512, белый фон, продукт целиком по центру (~80% кадра), без текста и рамок. Имя файла = имя из колонки `image_file` в `new_data/current_catalog.csv` (для замены фото) или транслит названия для нового продукта.
