Мой диабет

Помощник для семьи ребёнка с диабетом 1 типа

Приложение

Бесплатно, без регистрации. Откройте и установите на телефон.

Открыть приложение
  1. Android: Chrome → «Установить приложение» (или меню с тремя точками → «Добавить на главный экран»).
  2. iPhone: Safari → «Поделиться» → «На экран Домой».
