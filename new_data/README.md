# new_data

Изолированная папка для подготовки новых файлов с данными (база продуктов и т.п.).

Приложение эту папку **не использует**: ни `index.html`, ни модули в `core/`, `adapters/`, `i18n/`, ни `server/` на неё не ссылаются. Файлы здесь не влияют на рабочую версию до отдельной интеграции.

`current_catalog.csv` — выгрузка текущей базы (286 позиций) из `data/catalog.js` для сверки: id, название, категория, КБЖУ на 100 г, имя файла фото. У существующих продуктов `id` сохраняется; новые продукты получают новые `id`.
